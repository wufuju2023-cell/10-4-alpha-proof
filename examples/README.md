## 写法约定

1. **数字可复现**：所有输入都是脚本里写死的常量；
2. **中间量必须打印**：概率、Δ、梯度、更新前后值；
3. **闭式/理论结论要有断言**：如 `p*(A) = p_old·e^(r/2β)`；
4. **梯度公式做有限差分校验**：解析 vs 数值，误差 < 1e-6；
5. 结论用一两句人话收尾，不堆术语。
