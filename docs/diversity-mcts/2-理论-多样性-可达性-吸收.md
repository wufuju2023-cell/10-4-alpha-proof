# 2 · 理论：无限动作空间下的多样性、可达性与吸收

> 承接 `1-.md`（"不同战术是否真的不同"：语义去重与两条合并规则）。
> 用途：为 `3-实验计划.md` 提供公式与判据；符号与口径以本文为准。
> 状态：分析稿（2026-10-07），未经实验验证，待 E1/E2 数据检验。

## 0. 三个可分离的命题

设策略 `π_θ(t|s)`（给定证明状态 `s` 输出战术串分布）、环境 `E`（Lean，确定性、可复验）、预算 `B`（Lean 验证次数）、动作价值 `Q^π`。

| 命题 | 问题 | 结论 |
|---|---|---|
| **C1 多样性** | 是否存在机制保证每次扩展采到"本质不同"的候选？ | **无一般保证**；可测量（D_sem），可构造部分保证（有限族混合、检索条件化） |
| **C2 可达性** | 有用分支是否落在预算可达的概率范围内？ | 有精确判据（采样窗）：`p* ≥ θ_B = ln(1/δ)/B`；可用现有日志直接测（E2） |
| **C3 吸收** | 搜索找到的改进能否被 CE 保证内化？ | 只有"记忆"层面有弱保证；**泛化是经验问题**，需要机制而非定理 |

## 1. 从"枚举+评估"到"采样+支撑"：覆盖保证的退化

**AlphaZero（有限动作空间）**：

```text
a* = argmax_a [ Q(s,a) + c·π(a|s)·√N/(1+n(a)) ]
```

任何 `π(a|s) > 0` 的动作最终 `n(a) → ∞`——搜索对全体动作有覆盖保证。第 37 手"五路肩冲"的 `1/10000` 是**先验**（只影响访问次序），不是采样密度；搜索仍然会评估它。

**AlphaProof（可数无限动作空间）**：

```text
Reach(s, B) = { K 次采样 × H 次扩展的并集 }，  B = K·H
```

没有任何算子可以评估"全体动作"。扩展 = 从 `π_θ` 采样 `K` 个候选再评估，因此：

- 搜索能看见的动作集是**随机的、模型依赖的**；
- **先验直接决定采样密度**——围棋里先验只决定顺序，这里先验决定"能否看见"。

## 2. 采样窗（C2 的定量形式）

**命题 1（采样窗）**：对状态 `s` 下的有用战术 `t*`，记 `p* = π_θ(t*|s)`。`B` 次独立采样中至少见到一次的概率为

```text
P(found) = 1 − (1 − p*)^B ≥ 1 − e^(−p*·B)
```

要使其 ≥ `1 − δ`，只需 `e^(−p*·B) ≤ δ`，即

```text
p* ≥ θ_B := ln(1/δ) / B
```

**实例（现有数据）**：1280 draws / 20 题 → 每题 `B ≈ 64`；取 `δ = 0.1`，`θ_B ≈ 2.3/64 ≈ 3.6%`。即：**先验低于 ~4% 的战术，当前波次系统性地看不见。** 要触及 `p* ~ 1e-4` 的策略，需要 `10^4` 量级的采样/题（或结构化提议把概率质量集中）。

（对照：围棋里 `1e-4` 的先验仍能被发现，因为动作集可枚举、搜索会评估它。这个对照是本理论的核心。）

**多步推广**：长度 `L` 的证明，每步有用战术采样概率 `p_i`、预算 `B_i`，值函数完美（只在已采样集合内筛选）时：

```text
P(找到完整证明) ≥ Π_i [ 1 − (1 − p_i)^(B_i) ]
```

**值函数的作用边界**：值函数只能在"已采样集合"内做排序；它**不能把 `p* < θ_B` 的候选变出来**。可达性（采样）与排序（评估）是两个正交瓶颈，要分开测、分开治。

**支撑集视角**：给定无限预算，可达性退化为"支撑条件 `p* > 0`"；现实预算下每步成本约为 `1/p*`，所以工程上是概率量级问题。

## 3. "本质不同"的语义学（C1）

在状态 `s` 下定义**语义等价**：

```text
t1 ≈_s t2  ⟺  E(s, t1) = E(s, t2)     （实现用 state_key：goal pp 的 JSON）
```

`K` 个候选的**语义多样性**：

```text
D_sem  = |{ E(s, t_i) }| / K   （去重后的状态数 / 样本数）
D_fam  = |{ head(t_i) }| / K   （战术族头部去重率：intro/cases/induction/simp/rw/…）
```

要点：

1. **token 多样性 ≠ 语义多样性**。温度采样制造的是 token 熵；大量差异（lemma 排序、写法）被 Lean 归一化到同一 `state_key`，会被去重规则合并。
2. **无保证**：存在"K 个样本、语义只有 1~2 种状态"的坍缩情形，必须实测（E1）。
3. **部分保证（有限族混合）**：把提议分布分解为

```text
π(t|s) = Σ_{f∈F} w_f(s) · π_θ(t | s, f)，   |F| 有限（战术族 / 工具集）
```

有限层 `F` 恢复覆盖保证（每族以不低于 ~w_min 的密度被提议）；无限性被推入"族内实例化"，那部分仍受采样窗约束。这是"在 AlphaProof 内最小重建 AlphaZero 式有限动作结构"的机制（E4）。

4. **坍缩风险**：自训练闭环只模仿成功路径 → 分布单向锐化 → 输出熵与 D_sem 逐波下降 → 搜索能看见的候选变少。必须把 D_sem、输出熵列入逐波监控指标。

## 4. 吸收（C3）：CE 的保证边界

设第 `t` 波产出已验证轨迹集 `D_t`，CE 更新 `π_{t+1}`。分两个层面：

### 4.1 可保证（弱）——记忆与保持

- 成功路径被 CE 拟合后，`π_{t+1}(a*|s) → 1`；轨迹复现概率受复合误差控制（DAgger 型界：长度 `L`、单步误差 `ε` 时完成概率 `≥ 1 − O(ε·L²)`）。
- 测试时搜索是**恢复机制**：把对模型的要求从"每步正确"降为"每步可恢复"。
- 在**回放 + SFT 混比 + 发布门控**下，训练集解出数**单调不减**（新成功被记住，旧能力被回放保护）。

### 4.2 不可保证——泛化

泛化取决于四个量，全部是经验性的：

| 量 | 含义 | 对应机制 |
|---|---|---|
| 可表示性 | LoRA `ΔW = BA` 的秩 ≤ r，多波吸收会饱和 | E5（秩扫描）/ E6 |
| 状态覆盖 | 训练状态来自旧策略搜索，评测状态来自新策略 | E6 / 课程闭环（E8） |
| 信号密度 | 一条 `L` 步证明只给 `L` 个 `(state, tactic)` 对 | hindsight 展开（已做）、释义增广 |
| 保持 | 无回放时灾难性遗忘 | 回放 / SFT 混比 / KL 锚 |

**训练目标差异（关键）**：

- AlphaZero：拟合**访问分布**（软目标）——包含"这个动作不好"的负信息；
- 官方 AlphaProof：只模仿**选中路径**（硬目标）——纯正样本。

软目标承载搜索过程中的全部比较信息，理论上吸收效率更高（E5 消融）。

**闭环缺口**：AlphaZero 有自对弈——状态分布随策略保鲜。固定题库不闭合"搜索 → 参数 → 新状态"循环，泛化需要主动制造（E8 课程闭环）。

## 5. 容量：记忆与推理的可分离性

- 事实性知识（引理库）与推理模式（选择与组合）在信息论上可分离：库 = 精确、无限的外部存储；参数只学"选择与组合"，其有效容量随之上升。
- **LoRA 秩是吸收的显式瓶颈**：秩 `r` 限制每波可写入的更新子空间（E5 的 `r ∈ {8,16,32,64}` 实验）。
- **现实判断**：官方 3B + 8×10⁷ 课程 vs 本地 7B + 20 题/1 波。**当前瓶颈几乎肯定不是参数量，而是数据规模与统计功效**；容量问题要到数万验证轨迹规模后才值得担心。

## 6. 对照总表

| 维度 | AlphaZero | AlphaProof |
|---|---|---|
| 动作集 | 有限、可枚举 | 可数无限、不可枚举 |
| 发现机制 | PUCT 保证全动作评估 | 采样窗 `p* ≥ θ_B` |
| 多样性 | 规则保证（选点天然不同） | 模型依赖，无保证；需族/检索机制 |
| 训练目标 | 访问分布（软，含负） | 选中路径（硬，仅正） |
| 状态分布 | 自我对弈闭环 | 固定题库，不闭合 → 需课程闭环 |
| 提升保证 | 策略改进定理（完备搜索下） | 仅记忆（训练集）；泛化 = 经验问题 |

## 7. 推论

1. "不存在保证采样到本质不同策略的机制"——**成立**；但可转化为三个可测量：`D_sem`（E1）、`θ_B` 与 `p*` 分布（E2）、吸收率（E5/E6）。
2. "搜索改进"要拆成**发现**（采样宽度、族覆盖、检索）与**排序**（值函数）两个瓶颈分开治。
3. "能力内化"要拆成**记忆**（有弱保证）与**泛化**（无保证，需机制）；把事实外化（E7）可同时缓解容量与泛化。
