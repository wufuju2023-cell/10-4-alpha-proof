## §5 实验卫生备忘

1. **logprob 口径**：E2 第一步必须解剖一个 `policy_requests` receipt，确认是序列 logprob 还是 token 累乘、是否已经过温度处理；写进报告。
2. **heldout 隔离**：v009/v010 只在最终对照使用；任何调参/选择都不得触碰。
3. **同战术多节点**：统计时分清 per-node 与 per-problem 预算；去重/未去重两个版本都报。
4. **失败样本**：invalid/timeout 的先验分布也要统计（对照项），不要只留成功样本。
5. **预算归一**：所有"提升"都要除以实际 Lean 调用数或 token 数。
