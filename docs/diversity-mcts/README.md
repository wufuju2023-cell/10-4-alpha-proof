核心结论（详见 2）：AlphaZero 的"搜索一定能找到更好选点"来自**有限动作空间的覆盖保证**；AlphaProof 的动作空间可数无限不可枚举，发现能力退化为**采样窗** `p* ≥ θ_B = ln(1/δ)/B`。是否真的有"搜索独有发现"、搜索改进能否被 CE 吸收，都是**可以测量**的经验问题，而不是可以默认成立的假设。
